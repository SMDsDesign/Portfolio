SHANKAR MAJUMDAR - PORTFOLIO WEBSITE
====================================

WHAT'S IN THIS FOLDER
  index.html        The whole site (layout, styles, animation, content, admin).
  images/           All 12 photos the site uses (WebP).
  admin/index.html  Shortcut so yoursite.com/admin opens the login.

PUT IT ONLINE
  Upload the whole folder, keeping the structure, to any static host:
  Netlify Drop (drag the folder onto app.netlify.com/drop), Vercel,
  GitHub Pages, Cloudflare Pages, or your own hosting via FTP/cPanel.
  index.html must stay next to the images/ folder.

  To just look at it on your computer, double-click index.html.
  You need an internet connection because fonts load from Google Fonts.

ADMIN (EDIT TEXT, IMAGES, LAYOUT)
  Open yoursite.com/admin or yoursite.com/#admin and log in with your
  existing admin ID and password.
  Clicking "Save & publish" downloads an updated index.html. Upload it
  to your host, replacing the old one, to make your edits live.
  Images you replace in admin are embedded inside that index.html.

PAGES
  yoursite.com/          Home (navy poster, wolf to lion scroll)
  yoursite.com/#profile  Profile page (monochrome widgets)
